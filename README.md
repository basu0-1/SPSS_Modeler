# 😂 Things SPSS Has Taught Me

### 🥇 Lesson #1

**Data is never as clean as it looks.**

---

### 🥈 Lesson #2

**There is always one column that makes everything weird.**

---

### 🥉 Lesson #3

If something doesn't work:

```text
Don't panic.
     ↓
Check the node.
     ↓
Check the data.
     ↓
Check the settings.
     ↓
Try again.
     ↓
Still doesn't work?
     ↓
Google. 😭
```
